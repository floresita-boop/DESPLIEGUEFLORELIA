# 📌 Descripción

Proyecto desarrollado con JavaScript donde se realizan diferentes cálculos matemáticos y pruebas automáticas utilizando GitHub Actions y GitHub Pages.

La aplicación permite:

✅ Contador regresivo  
✅ Suma de números pares  
✅ Mostrar números impares  
✅ Potencias  
✅ Secuencia Fibonacci  
✅ Test General  
✅ Test Individual dinámico  
✅ Despliegue automático en GitHub Pages
